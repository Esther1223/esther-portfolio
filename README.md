# Esther Liu · Portfolio

## 本機開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
npm run preview
```

## 部署到 GitHub Pages

已設定 `base: '/esther-portfolio/'`。

```bash
npm run deploy
```

或手動：GitHub → Settings → Pages → 部署 `gh-pages` branch（`deploy` script 會建立）。

網站網址：

`https://Esther1223.github.io/esther-portfolio/`
